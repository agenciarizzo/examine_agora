# Fotos reais da clínica

Coloque aqui os arquivos (jpg/webp) e registre cada um em `content/fotos.json`:

```json
{ "src": "/fotos/fachada.jpg", "alt": "Fachada da Examine Agora na Av. Recanto das Emas", "w": 1280, "h": 1707 }
```

A seção "A clínica por dentro" em `/sobre-nos` aparece sozinha assim que a lista
deixa de estar vazia.
